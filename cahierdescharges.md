# 11. Formulaire de contact

Le formulaire permettra aux visiteurs de contacter directement Dah YEKOUMEDJI.

## Champs

- Nom
- Adresse e-mail
- Téléphone
- Sujet
- Message

## Fonctionnement

Les informations seront envoyées vers un script PHP.

Le script utilisera la fonction native **PHP Mail** afin d'expédier automatiquement le message à :

**contact@dah-yekoumedji.org**

Après l'envoi :

- Affichage d'un message de confirmation.
- Affichage d'un message d'erreur en cas de problème.

## Stockage des données

Aucune donnée saisie dans le formulaire ne sera :

- Enregistrée.
- Conservée.
- Archivée.
- Stockée dans une base de données.

Les informations seront uniquement utilisées pour générer l'e-mail envoyé au destinataire.
